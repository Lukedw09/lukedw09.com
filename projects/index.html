01 Live

Astraeus

Aerospace engineering assistant

I built Astraeus, an AI aerospace engineering assistant that runs checked calculation programs. The public source is on GitHub, and I run the same assistant on the web at astraeus.de-wet.com.

  • Hohmann transfers
  • Orbital parameters
  • Nozzle area–Mach
  • Throat sizing
  • Motor performance
  • Standard atmosphere
  • V–n diagrams

astraeus.de-wet.com github.com/Lukedw09/AerospaceBot

02 Live

FlightLog

Flight-data analysis and simulation

I built FlightLog, a web tool for flight-data analysis and simulation. I use it to take a CSV from a launch, or to simulate one, and it draws elevation and pressure against time.

flightlog.lukedw09.com github.com/Lukedw09/FlightLog

03 Completed

Mavic Mini flight logger

Arduino Nano and BMP180

I built an Arduino Nano and BMP180 logger for a DJI Mavic Mini. It sits in a 3D-printed top mount and writes pressure, temperature, and altitude to a microSD card. I flew it up to about 150 m, and it logged how those changed on the way up.

05 Live

StarbaseLaunchApp

Starship launch hub

I built a hub for the next Starship launch at Starbase, Texas, and a launch-day companion for when a flight is close. Between flights it shows the next flight, past flights, vehicles, a viewing guide, and news. It is an unofficial fan app and is not affiliated with SpaceX.

starbaselaunchapp.lukedw09.com github.com/Lukedw09/StarbaseLaunchApp

06 Live

SatPass

Satellite passes

I built a browser satellite-pass predictor. It shows when the ISS, Tiangong, Hubble, and other bright satellites cross the sky, and which of those passes can be seen with the naked eye. It opens on Los Angeles.

satpass.lukedw09.com github.com/Lukedw09/satpass
